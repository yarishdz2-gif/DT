ZYROX — Sitio estático para Vercel

PUBLICAR:
1. Sube index.html y vercel.json a la raíz de un repositorio de GitHub.
2. En Vercel, crea un proyecto nuevo e importa ese repositorio.
3. Framework Preset: Other.
4. Build Command: dejar vacío.
5. Output Directory: dejar vacío o usar la raíz del proyecto.
6. Pulsa Deploy.

La página no necesita servidor ni dependencias. El formulario de reclutamiento prepara una solicitud en el navegador; no la envía ni la guarda en una base de datos. Para recibir solicitudes automáticamente, se necesita integrar un backend o un servicio de formularios.
